# Todo 리스트

JavaScript DOM 조작과 localStorage를 사용해서 만든 간단한 Todo 리스트입니다.

## 기능

- 할 일 추가
- 할 일 목록 조회
- 할 일 수정
- 할 일 삭제
- 새로고침 후 데이터 유지

## 스타일

Tailwind CSS CDN을 사용했습니다.

## 파일 구조

```text
index.html
css/style.css
js/todo.js
```

## 실행 방법

`index.html` 파일을 브라우저에서 열면 실행됩니다.
